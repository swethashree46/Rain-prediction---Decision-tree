Project Overview

This project aims to predict rainfall based on various meteorological factors such as temperature, humidity, wind speed, atmospheric pressure, and precipitation levels. The Decision Tree Classifier is implemented to analyze these features and determine whether it will rain or not. To handle categorical data like city names, Label Encoding is applied to convert them into numerical values for effective model training.

Objectives

✅ Predict whether it will rain based on input weather conditions✅ Implement Label Encoding for categorical data✅ Train and evaluate a Decision Tree Classifier✅ Export the processed dataset for further analysis
